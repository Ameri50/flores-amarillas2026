# flores-amarillas2026 🌻

Página animada de regalo inspirada en un video de TikTok: cielo estrellado, pétalos cayendo, reproductor decorativo con barra de progreso, y un jardín de girasoles generado por código (SVG + CSS) que crecen y se balancean.

## Uso
Abre `index.html` en el navegador. Es un solo archivo autocontenido (HTML + CSS + JS), sin dependencias externas salvo Google Fonts.

## Personalizar
- Texto: edita `#titulo` y `#mensaje` en el HTML.
- Cantidad de flores: cambia `FLOWER_COUNT` en el `<script>`.
- Colores: variables CSS en `:root` (`--gold`, `--leaf`, etc).
